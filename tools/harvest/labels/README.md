# Album picks for the harvested photo sets

One file per set, `<set id>.txt`, one file name per line (`IMG_0007.jpg`): the photos a careful
person would put in the album, chosen from the numbered contact sheets (harvest-sheets branch).

How the picks are made (so the score means something):

- Picked by looking at the photos only, before running the app on the set. Never changed after
  seeing what the app chose.
- About 15-25% of a set, more for a small set of strong photos, fewer for a weak one; enough to
  tell the story: the main people, every big moment, family, a few details.
- One photo per moment unless the moment is big; the best frame of a burst.
- `HarvestScoreTest` holds back about a third of the sets (fixed by the set's name). Those are
  the honest score: never look at what the app does on them while changing the brain.

These picks are Claude's (a stand-in for a couple), not a real couple's.
